# 오토마타 이론

오토마타(Automata)는 입력에 따라 상태를 바꾸며 특정 언어를 인식하는 추상적인 기계 모델이다. 주어진 문자열이 언어에 속하는지 판단하는 과정을 표현하므로 컴파일러의 어휘 분석기(Lexer), 정규 표현식 엔진, 프로토콜 검증 등에 쓰인다.

## 유한 오토마타 (Finite Automata, FA)

유한 오토마타는 유한한 상태 집합과 상태 전이 규칙으로 정규 언어를 인식한다. 같은 입력에 대해 다음 상태가 하나로 정해지는지에 따라 DFA와 NFA로 나뉜다.

### DFA (Deterministic Finite Automaton)

- 정의: 5-튜플 M = (Q, Σ, δ, q₀, F)
- Q: 유한한 상태 집합
- Σ: 입력 알파벳
- δ: Q × Σ → Q (전이 함수, 결정적)
- q₀: 시작 상태 (q₀ ∈ Q)
- F: 수락 상태 집합 (F ⊆ Q)

각 상태에서 입력 기호 하나에 대한 전이는 정확히 하나다. 따라서 다음 상태를 선택할 필요 없이 입력을 차례로 읽으면 되며, 입력 길이가 n일 때 실행 시간은 O(n)이다.

- 예시: 짝수 개의 0을 포함하는 이진 문자열
- 상태: {q_even, q_odd}
- 알파벳: {0, 1}
- 시작 상태: q_even
- 수락 상태: {q_even}
- 전이 함수:
- δ(q_even, 0) = q_odd
- δ(q_even, 1) = q_even
- δ(q_odd, 0) = q_even
- δ(q_odd, 1) = q_odd

0을 읽을 때마다 `q_even`과 `q_odd` 사이를 오가고, 1을 읽으면 현재 상태를 유지한다. 입력 `"1001"`은 `q_even →(1)→ q_even →(0)→ q_odd →(0)→ q_even →(1)→ q_even`으로 처리된다. 마지막 상태가 수락 상태인 `q_even`이므로 문자열을 수락한다.

### NFA (Nondeterministic Finite Automaton)

- 정의: 5-튜플 M = (Q, Σ, δ, q₀, F)
- δ: Q × Σ → P(Q) (전이 함수, 상태의 집합 반환)

NFA는 같은 상태와 입력에 대해 전이가 없을 수도, 여러 개일 수도 있다. 가능한 경로 중 하나라도 수락 상태에 도달하면 문자열을 수락한다. 이 방식은 DFA보다 설계가 직관적일 수 있지만, 실행할 때는 여러 경로를 시뮬레이션해야 한다.

- 예시: "ab"로 끝나는 문자열
- 상태: {q0, q1, q2}
- 알파벳: {a, b}
- 시작 상태: q0
- 수락 상태: {q2}
- 전이 함수:
- δ(q0, a) = {q0, q1}, // 비결정적: 두 상태로 전이 가능
- δ(q0, b) = {q0}
- δ(q1, a) = ∅
- δ(q1, b) = {q2}
- δ(q2, a) = ∅
- δ(q2, b) = ∅
- 상태 전이 다이어그램:
- a, b
- a, b
- →, q0, →, q1, →, q2
- (수락)
- 입력 "aab" 처리 (모든 경로 추적):
- q0 →(a)→ {q0, q1}
- q0 →(a)→ {q0, q1}
- q0 →(b)→ {q0} (수락 X)
- q1 →(b)→ {q2} (수락 O!)
- q1 →(a)→ ∅ (죽은 경로)

### ε-NFA (Epsilon-NFA)

- 정의: 입력 없이 상태 전이 가능한 NFA
- δ: Q × (Σ ∪ {ε}) → P(Q)

- 특징:
- ε-전이: 입력을 소비하지 않고 상태 이동
- 정규 표현식을 NFA로 변환할 때 유용

- 예시: (a b)\*c를 인식하는 ε-NFA
- ε, ε
- → q1, a→ q2
- ε
- → q0, ε → q3, b→ q4, ε
- ε
- → q5, c→ (q6)
- 수락
- ε-클로저(q0) = {q0, q1, q3, q5}

## NFA → DFA 변환 (Subset Construction)

모든 NFA는 같은 언어를 인식하는 DFA로 변환할 수 있다. 여러 경로에서 도달할 수 있는 NFA 상태들을 하나의 DFA 상태로 묶는 부분집합 구성법(Subset Construction), 또는 멱집합 구성법(Powerset Construction)을 사용한다.

DFA의 시작 상태는 NFA 시작 상태의 ε-closure다. 각 상태 집합에 입력 기호를 적용해 다음 집합을 계산하고, NFA의 수락 상태를 포함한 집합을 DFA의 수락 상태로 지정한다.

- {q0}:
  - a: {q0,q1}
  - b: {q0}
- {q0,q1}:
  - a: {q0,q1}
  - b: {q0,q2}
- {q0,q2}:
  - a: {q0,q1}
  - b: {q0}
- 예시: "ab"로 끝나는 문자열 NFA를 DFA로 변환
- NFA 전이:
- δ(q0, a) = {q0, q1}
- δ(q0, b) = {q0}
- δ(q1, b) = {q2}
- DFA 상태 = NFA 상태의 부분집합
- {q0}         // 시작 상태
- {q0, q1}     // q0에서 a 입력
- {q0, q2}     // {q0,q1}에서 b 입력 = δ(q0,b) ∪ δ(q1,b) = {q0} ∪ {q2}
- DFA 전이 테이블:
- 수락 상태: {q0,q2} (q2 포함)
- 상태 수: NFA는 3개, DFA는 3개
- 최악의 경우 DFA 상태 수는 2ⁿ (n = NFA 상태 수)

## DFA 최소화

DFA 최소화는 동등한 상태를 합쳐 상태 수를 줄이는 과정이다. Hopcroft 알고리즘(O(n log n))은 먼저 수락 상태와 비수락 상태를 나눈다. 같은 그룹에 속하더라도 입력에 따라 서로 다른 그룹으로 전이하면 다시 분리하며, 더 나눌 수 없을 때까지 반복한다.

- 예시:
- 원본 DFA (5개 상태):
- q0, a→ q1, b→ q2 (수락)
- q0, b→ q3, a→ q4, b→ q2
- 분할 과정:
- 초기: {q0, q1, q3, q4}, {q2}
- q1과 q4는 b로 수락 상태로 가므로 분리 필요
- 결과: {q0, q3}, {q1, q4}, {q2}
- q0과 q3: a 입력 시 둘 다 {q1,q4} 그룹으로
- b 입력 시 q0→{q1,q4}, q3→{q0,q3} (다름!)
- 분리: {q0}, {q3}, {q1, q4}, {q2}
- 최소화된 DFA (4개 상태)

## 정규표현식과 FA의 관계

정규 표현식과 유한 오토마타는 같은 언어 클래스를 표현한다. 정규 표현식에서 출발하면 Thompson 구성법으로 NFA를 만들고, 부분집합 구성법으로 DFA로 바꾼 뒤 최소화할 수 있다. 반대로 상태 제거(State Elimination)를 통해 오토마타에서 정규 표현식을 얻을 수도 있다.

### Thompson's Construction (RE → NFA)

- 정규 표현식의 각 연산에 대해 ε-NFA를 구성:

- 기본 케이스:
- ε:, → (q0), ε→ ((q1))
- a:, → (q0), a→ ((q1))
- 연결 (AB):
- → (s1), A → (f1), ε→ (s2), B → ((f2))
- 선택 (A B):
- ε, A → (f1), ε
- → (s), → ((f))
- ε, B → (f2), ε
- 클로저 (A\*):
- ε
- → (s), ε→ (s1), A→ (f1), ε→ ((f))
- ε

- 예시: (a|b)\*abb의 NFA

- Thompson's Construction 적용:
- a를 위한 NFA:, q1, a→ q2
- b를 위한 NFA:, q3, b→ q4
- (a b):, q0, ε→ q1, a→ q2, ε→ q5
- q0, ε→ q3, b→ q4, ε→ q5
- (a b)\*:, q6, ε→ q0 ... q5, ε→ q7
- q6, ε→ q7
- q5, ε→ q0 (루프)
- abb 추가:, ..., ε→ q8, a→ q9, b→ q10, b→ q11 (수락)

## Pushdown Automata (PDA)

푸시다운 오토마타는 유한 오토마타에 스택을 더한 모델로, 문맥 자유 언어를 인식한다. 아래 `aⁿbⁿ` 예제에서는 a를 읽을 때 스택에 기호를 넣고 b를 읽을 때 꺼내면서 개수를 맞춘다.

- 정의: 7-튜플 M = (Q, Σ, Γ, δ, q₀, Z₀, F)
- Q: 상태 집합
- Σ: 입력 알파벳
- Γ: 스택 알파벳
- δ: Q × (Σ ∪ {ε}) × Γ → P(Q × Γ\*)
- q₀: 시작 상태
- Z₀: 초기 스택 기호
- F: 수락 상태 집합

- 예시: L = {aⁿbⁿ, n ≥ 0}을 인식하는 PDA
- 상태: {q0, q1, q2}
- 입력 알파벳: {a, b}
- 스택 알파벳: {A, Z}, // Z는 스택 바닥 표시
- 시작: q0, 스택에 Z
- 전이:
- δ(q0, a, Z) = {(q0, AZ)}, // a 읽고 A를 push
- δ(q0, a, A) = {(q0, AA)}, // a 읽고 A를 push
- δ(q0, b, A) = {(q1, ε)}, // b 읽고 A를 pop
- δ(q1, b, A) = {(q1, ε)}, // b 읽고 A를 pop
- δ(q1, ε, Z) = {(q2, Z)}, // 스택 비면 수락
- 입력 "aabb" 처리:
- (q0, aabb, Z) ⊢ (q0, abb, AZ) ⊢ (q0, bb, AAZ)
- ⊢ (q1, b, AZ), ⊢ (q1, ε, Z)
- ⊢ (q2, ε, Z), 수락!
- 스택 시각화:
- 초기:, [Z]
- a:, [A,Z]
- a:, [A,A,Z]
- b:, [A,Z], (A pop)
- b:, [Z], (A pop)
- ε:, 수락 상태로 전이

## DPDA vs NPDA

DPDA(Deterministic PDA)는 각 구성에서 최대 하나의 전이를 가지며 LR 파서의 기반이 된다. NPDA(Nondeterministic PDA)는 여러 전이를 허용해 모든 문맥 자유 언어(CFL)를 인식한다. 인식 가능한 언어의 범위로 보면 DPDA는 NPDA의 진부분집합이다.

예를 들어 `L = {wwᴿ | w ∈ {a,b}*}`는 NPDA가 중간 지점을 추측해 인식할 수 있지만, DPDA는 중간 지점을 결정할 수 없어 인식하지 못한다. 가운데 표시를 넣은 `L = {wcwᴿ | w ∈ {a,b}*}`는 DPDA도 c를 읽는 순간 중간임을 알 수 있어 인식할 수 있다.
