# 병합 정렬

병합 정렬은 배열을 절반으로 나누어 각각 정렬한 뒤, 정렬된 두 구간을 합친다. 분할 정복(Divide and Conquer)의 한 예로, 작은 문제의 결과를 병합(Merge)하는 과정에서 전체 순서를 만든다.

- 핵심 특성:
- 시간 복잡도: O(n log n) - 항상 보장
- 공간 복잡도: O(n) - 추가 배열 필요
- 안정 정렬(Stable Sort)
- 외부 정렬(External Sort)에 적합

## 정렬 알고리즘

### Merge Sort (병합 정렬)

```java
public class MergeSort {
    public static void mergeSort(int[] arr, int left, int right) {
        if (left < right) {
            int mid = left + (right - left) / 2;

            mergeSort(arr, left, mid);      // 왼쪽 정렬
            mergeSort(arr, mid + 1, right); // 오른쪽 정렬
            merge(arr, left, mid, right);   // 병합
        }
    }

    private static void merge(int[] arr, int left, int mid, int right) {
        // 임시 배열 생성
        int[] leftArr = Arrays.copyOfRange(arr, left, mid + 1);
        int[] rightArr = Arrays.copyOfRange(arr, mid + 1, right + 1);

        int i = 0, j = 0, k = left;

        // 두 배열 병합
        while (i < leftArr.length && j < rightArr.length) {
            if (leftArr[i] <= rightArr[j]) {
                arr[k++] = leftArr[i++];
            } else {
                arr[k++] = rightArr[j++];
            }
        }

        // 나머지 복사
        while (i < leftArr.length) arr[k++] = leftArr[i++];
        while (j < rightArr.length) arr[k++] = rightArr[j++];
    }
}
```

- 원본: [38, 27, 43, 3, 9, 82, 10]
- 분할(Divide):
- [38, 27, 43, 3], [9, 82, 10]
- [38, 27], [43, 3], [9, 82], [10]
- [38], [27], [43], [3], [9], [82], [10]
- 정복(Conquer) & 병합(Combine):
- [27, 38], [3, 43], [9, 82], [10]
- [3, 27, 38, 43], [9, 10, 82]
- [3, 9, 10, 27, 38, 43, 82]

## 기본 구현 (Top-Down)

```python
def merge_sort(arr):
    """Top-down 재귀적 병합 정렬"""
    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2
    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    return merge(left, right)

def merge(left, right):
    """두 정렬된 배열을 병합"""
    result = []
    i = j = 0

    while i < len(left) and j < len(right):
        if left[i] <= right[j]:  # <= 로 안정성 보장
            result.append(left[i])
            i += 1
        else:
            result.append(right[j])
            j += 1

    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

```java
public static void mergeSort(int[] arr, int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;  // 오버플로우 방지

        mergeSort(arr, left, mid);
        mergeSort(arr, mid + 1, right);
        merge(arr, left, mid, right);
    }
}

public static void merge(int[] arr, int left, int mid, int right) {
    int[] temp = new int[right - left + 1];
    int i = left, j = mid + 1, k = 0;

    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j]) {
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
        }
    }

    while (i <= mid) temp[k++] = arr[i++];
    while (j <= right) temp[k++] = arr[j++];

    System.arraycopy(temp, 0, arr, left, temp.length);
}
```

## 시간 복잡도 분석

크기가 n/2인 두 구간을 재귀적으로 정렬하고, 두 구간의 원소를 병합하는 데 Θ(n)을 사용한다. 따라서 점화식은 `T(n) = 2T(n/2) + Θ(n)`이다.

- Master Theorem 적용:
- a = 2, b = 2, f(n) = n
- n^(log_b(a)) = n^(log_2(2)) = n
- f(n) = Θ(n^(log_b(a)))  → Case 2
- T(n) = Θ(n log n)

재귀 트리에서는 구간 크기가 n, n/2, n/4로 줄어드는 동안 구간 수가 1, 2, 4로 늘어난다. 같은 레벨의 원소 수 합은 n이고 깊이는 log n이므로, 레벨별 병합 비용을 합하면 Θ(n log n)이 된다.

## 공간 복잡도 분석

재귀 호출의 깊이는 O(log n)이지만 병합에 필요한 임시 배열이 O(n)이므로 전체 보조 공간은 O(n)이다. 다음 구현은 병합할 때마다 배열을 새로 만들지 않고 보조 배열을 재사용한다.

```python
def merge_sort_inplace(arr, aux, left, right):
    """보조 배열을 재사용하는 버전"""
    if left >= right:
        return

    mid = (left + right) // 2
    merge_sort_inplace(arr, aux, left, mid)
    merge_sort_inplace(arr, aux, mid + 1, right)
    merge_inplace(arr, aux, left, mid, right)

def merge_inplace(arr, aux, left, mid, right):
    # 보조 배열에 복사
    for i in range(left, right + 1):
        aux[i] = arr[i]

    i, j = left, mid + 1
    for k in range(left, right + 1):
        if i > mid:
            arr[k] = aux[j]
            j += 1
        elif j > right:
            arr[k] = aux[i]
            i += 1
        elif aux[i] <= aux[j]:
            arr[k] = aux[i]
            i += 1
        else:
            arr[k] = aux[j]
            j += 1
```

## Bottom-Up 병합 정렬

크기가 1인 구간부터 두 개씩 합쳐 나가면 재귀 없이도 같은 병합 과정을 구현할 수 있다. 아래 코드는 구간 크기를 1, 2, 4로 늘리면서 인접한 구간을 합친다.

```python
def merge_sort_bottom_up(arr):
    """Bottom-up 반복적 병합 정렬"""
    n = len(arr)
    aux = arr.copy()

    size = 1
    while size < n:
        for left in range(0, n, 2 * size):
            mid = min(left + size - 1, n - 1)
            right = min(left + 2 * size - 1, n - 1)

            if mid < right:
                merge_bottom_up(arr, aux, left, mid, right)

        size *= 2

    return arr

def merge_bottom_up(arr, aux, left, mid, right):
    for i in range(left, right + 1):
        aux[i] = arr[i]

    i, j = left, mid + 1
    for k in range(left, right + 1):
        if i > mid:
            arr[k] = aux[j]
            j += 1
        elif j > right:
            arr[k] = aux[i]
            i += 1
        elif aux[i] <= aux[j]:
            arr[k] = aux[i]
            i += 1
        else:
            arr[k] = aux[j]
            j += 1
```

- Bottom-Up 장점:
- 재귀 호출 오버헤드 없음
- 연결 리스트에 자연스럽게 적용
- 외부 정렬(External Sort)에 적합

## 안정성(Stability) 증명

- 정의: 동일한 키를 가진 원소들의 상대적 순서가 정렬 후에도 유지됨.

- 증명:

```python
# merge 함수에서 left[i] <= right[j]일 때 left를 먼저 선택
if left[i] <= right[j]:  # 등호 중요!
    result.append(left[i])
```

값이 같을 때 왼쪽 원소를 먼저 선택하면 원래 앞에 있던 원소가 병합 뒤에도 앞에 남는다. 비교식을 다음처럼 `<`로 바꾸면 같은 값에서 오른쪽 원소가 먼저 선택될 수 있어 안정성이 깨진다.

```python
# < 사용 시 안정성 깨짐
if left[i] < right[j]:  # 엄격한 부등호
    result.append(left[i])
```

## 자연 병합 정렬 (Natural Merge Sort)

입력에 이미 정렬된 구간(run)이 있다면 그 구간을 다시 나누지 않고 병합에 활용할 수 있다. 자연 병합 정렬은 먼저 이런 구간을 찾은 뒤 인접한 구간들을 합친다.

```python
def natural_merge_sort(arr):
    """자연 병합 정렬 - 기존 정렬된 run 활용"""

    def find_runs(arr):
        """오름차순 run 찾기"""
        runs = []
        i = 0
        while i < len(arr):
            start = i
            while i < len(arr) - 1 and arr[i] <= arr[i + 1]:
                i += 1
            runs.append((start, i))
            i += 1
        return runs

    while True:
        runs = find_runs(arr)
        if len(runs) == 1:
            break

        # 인접한 run들을 병합
        for i in range(0, len(runs) - 1, 2):
            left_start, left_end = runs[i]
            right_start, right_end = runs[i + 1]
            merge_inplace(arr, left_start, left_end, right_end)

    return arr
```
