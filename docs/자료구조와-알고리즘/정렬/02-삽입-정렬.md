# 삽입 정렬

삽입 정렬은 손에 든 카드를 정리하듯이 정렬된 구간을 조금씩 늘린다. 아직 정렬하지 않은 원소를 하나 꺼내 앞쪽 구간의 알맞은 위치에 넣고, 뒤에 남은 원소에도 같은 작업을 반복한다.

- 핵심 특성:
- 시간 복잡도: O(n²) 최악/평균, O(n) 최선
- 공간 복잡도: O(1) - 제자리 정렬
- 안정 정렬(Stable Sort)
- 적응적(Adaptive): 거의 정렬된 입력에서 매우 효율적

## 알고리즘 동작 원리

- 초기 배열: [5, 2, 4, 6, 1, 3]
- i=1: 2를 삽입 → [2, 5, 4, 6, 1, 3]
- 정렬됨: [2, 5]
- i=2: 4를 삽입 → [2, 4, 5, 6, 1, 3]
- 정렬됨: [2, 4, 5]
- i=3: 6을 삽입 → [2, 4, 5, 6, 1, 3]
- 정렬됨: [2, 4, 5, 6]
- i=4: 1을 삽입 → [1, 2, 4, 5, 6, 3]
- 정렬됨: [1, 2, 4, 5, 6]
- i=5: 3을 삽입 → [1, 2, 3, 4, 5, 6]
- 정렬됨: [1, 2, 3, 4, 5, 6]

## 기본 구현

```python
def insertion_sort(arr):
    """기본 삽입 정렬"""
    for i in range(1, len(arr)):
        key = arr[i]
        j = i - 1

        # key보다 큰 원소들을 오른쪽으로 이동
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1

        arr[j + 1] = key

    return arr
```

```java
public static void insertionSort(int[] arr) {
    for (int i = 1; i < arr.length; i++) {
        int key = arr[i];
        int j = i - 1;

        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }

        arr[j + 1] = key;
    }
}
```

## Loop Invariant를 통한 정확성 증명

반복문 i가 시작할 때 `arr[0..i-1]`에 원래 그 구간의 원소들이 정렬된 순서로 들어 있다는 조건을 불변식으로 잡는다.

1. 초기화: i=1이면 앞쪽 구간에는 원소 하나만 있으므로 이미 정렬돼 있다.
2. 유지: `key`보다 큰 원소들을 오른쪽으로 옮긴 뒤 빈자리에 `key`를 넣으면 `arr[0..i]`까지 정렬된다.
3. 종료: i=n이 되면 불변식이 가리키는 구간이 배열 전체이므로 정렬이 끝난다.

## 시간 복잡도 분석

```python
def insertion_sort_with_analysis(arr):
    comparisons = 0
    swaps = 0

    for i in range(1, len(arr)):         # n-1번
        key = arr[i]
        j = i - 1

        while j >= 0 and arr[j] > key:   # 최대 i번
            comparisons += 1
            arr[j + 1] = arr[j]
            swaps += 1
            j -= 1

        if j >= 0:
            comparisons += 1  # while 탈출 시 마지막 비교

        arr[j + 1] = key

    return arr, comparisons, swaps
```

- 케이스별 분석:

- 케이스: 최선 (이미 정렬):
  - 비교 횟수: n-1
  - 이동 횟수: 0
  - 시간 복잡도: O(n)
- 케이스: 최악 (역순 정렬):
  - 비교 횟수: n(n-1)/2
  - 이동 횟수: n(n-1)/2
  - 시간 복잡도: O(n²)
- 케이스: 평균:
  - 비교 횟수: n(n-1)/4
  - 이동 횟수: n(n-1)/4
  - 시간 복잡도: O(n²)

- 최악의 경우 유도:
- 역순 배열: [n, n-1, n-2, ..., 2, 1]
- i=1: 1번 비교, 1번 이동
- i=2: 2번 비교, 2번 이동
- i=n-1: (n-1)번 비교, (n-1)번 이동
- 총합: 1 + 2 + ... + (n-1) = n(n-1)/2 = O(n²)

## Adaptive 특성

앞에 있는 값이 뒤의 값보다 큰 쌍, 즉 `i < j`이면서 `arr[i] > arr[j]`인 쌍을 역전(Inversion)이라고 한다. 삽입 정렬은 원소를 옮기며 이런 역전을 해소하므로, 입력이 얼마나 정렬돼 있는지에 따라 비용이 달라진다.

```python
def count_inversions(arr):
    """역전의 개수 세기"""
    count = 0
    for i in range(len(arr)):
        for j in range(i + 1, len(arr)):
            if arr[i] > arr[j]:
                count += 1
    return count
```

- 정리: 삽입 정렬의 실행 시간은 O(n + I)임. 여기서 I는 역전의 수.

- 완전히 정렬된 배열: I = 0 → O(n)
- 역순 배열: I = n(n-1)/2 → O(n²)
- k개의 원소만 잘못된 위치: I ≤ k(n-1) → O(kn)

## Binary Insertion Sort

앞쪽 구간은 이미 정렬돼 있으므로 삽입 위치를 이진 탐색으로 찾을 수 있다. 아래 구현은 위치를 찾는 비교 횟수를 줄이지만, 원소를 옮기는 작업까지 없애지는 않는다.

```python
import bisect

def binary_insertion_sort(arr):
    """이진 탐색을 활용한 삽입 정렬"""
    for i in range(1, len(arr)):
        key = arr[i]

        # 이진 탐색으로 삽입 위치 찾기: O(log i)
        pos = bisect.bisect_left(arr, key, 0, i)

        # 원소 이동은 여전히 O(i)
        arr[pos+1:i+1] = arr[pos:i]
        arr[pos] = key

    return arr
```

- 분석:
- 비교 횟수: O(n log n)
- 이동 횟수: O(n²) (여전히)
- 총 시간 복잡도: O(n²)

- 이진 삽입 정렬은 비교 비용이 큰 경우(예: 문자열, 복잡한 객체)에 유용.

## Shell Sort - 삽입 정렬의 확장

삽입 정렬은 멀리 떨어진 위치로 가야 하는 원소도 한 칸씩 옮긴다. Shell Sort는 처음에는 큰 간격으로 원소를 비교하고, 점차 간격을 줄여 마지막에 일반적인 삽입 정렬을 수행한다.

```python
def shell_sort(arr):
    """Shell Sort - 간격 시퀀스를 사용한 삽입 정렬 개선"""
    n = len(arr)
    gap = n // 2

    while gap > 0:
        # gap 간격으로 삽입 정렬
        for i in range(gap, n):
            temp = arr[i]
            j = i

            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap

            arr[j] = temp

        gap //= 2

    return arr
```

- 간격 시퀀스에 따른 복잡도:

- 시퀀스: Shell's (n/2, n/4, ..., 1):
  - 복잡도: O(n²)
- 시퀀스: Hibbard's (2^k - 1):
  - 복잡도: O(n^1.5)
- 시퀀스: Sedgewick's:
  - 복잡도: O(n^4/3)
- 시퀀스: Ciura's empirical:
  - 복잡도: 매우 좋은 실제 성능

```python
def shell_sort_ciura(arr):
    """Ciura의 경험적 간격 시퀀스"""
    gaps = [701, 301, 132, 57, 23, 10, 4, 1]
    n = len(arr)

    for gap in gaps:
        if gap >= n:
            continue

        for i in range(gap, n):
            temp = arr[i]
            j = i

            while j >= gap and arr[j - gap] > temp:
                arr[j] = arr[j - gap]
                j -= gap

            arr[j] = temp

    return arr
```
