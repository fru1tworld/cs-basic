# 동적 프로그래밍

## 동적 프로그래밍

### DP 기본 개념

동적 프로그래밍은 반복해서 등장하는 부분 문제의 답을 저장해 다시 계산하는 비용을 줄인다. 최적화 문제에 적용하려면 전체 문제의 최적해를 부분 문제의 최적해로 구성할 수 있어야 한다. 이를 최적 부분 구조(Optimal Substructure)라고 하며, 같은 부분 문제가 반복되는 성질은 중복되는 부분 문제(Overlapping Subproblems)라고 한다.

답을 저장하는 순서에 따라 접근 방법이 나뉜다. Top-Down(Memoization)은 재귀 호출 중 필요한 답을 구해 캐싱하고, Bottom-Up(Tabulation)은 반복문으로 작은 부분 문제부터 테이블을 채운다.

### 대표 DP 문제

피보나치 수열은 두 접근 방법을 비교하기 좋은 예다. 앞의 두 결과만 있으면 다음 값을 계산할 수 있으므로, 마지막 구현에서는 테이블 대신 두 변수만 유지한다.

```python
# 1. 피보나치 수열
# Top-Down (Memoization)
from functools import lru_cache

@lru_cache(maxsize=None)
def fib_memo(n):
    if n <= 1:
        return n
    return fib_memo(n-1) + fib_memo(n-2)

# Bottom-Up (Tabulation)
def fib_tabulation(n):
    if n <= 1:
        return n
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]

# 공간 최적화
def fib_optimized(n):
    if n <= 1:
        return n
    prev2, prev1 = 0, 1
    for _ in range(2, n + 1):
        curr = prev1 + prev2
        prev2, prev1 = prev1, curr
    return prev1
```

최장 공통 부분 수열(LCS)은 두 문자열의 접두사에 대한 답을 테이블에 저장한다. 아래 코드는 현재 문자가 같은지에 따라 이전 결과를 이어받는 위치를 결정한다.

```java
// 2. 최장 공통 부분 수열 (LCS)
public class LCS {
    public static int lcs(String s1, String s2) {
        int m = s1.length();
        int n = s2.length();
        int[][] dp = new int[m + 1][n + 1];

        // dp[i][j] = s1[0..i-1]과 s2[0..j-1]의 LCS 길이
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (s1.charAt(i-1) == s2.charAt(j-1)) {
                    dp[i][j] = dp[i-1][j-1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
                }
            }
        }

        return dp[m][n];
    }
}
```

0/1 배낭 문제에서는 각 물건을 넣는 경우와 넣지 않는 경우의 가치를 비교한다. 공간을 줄인 구현은 같은 물건을 중복해서 쓰지 않도록 용량을 역순으로 순회한다.

```python
# 3. 0/1 배낭 문제 (Knapsack)
def knapsack(weights, values, capacity):
    n = len(weights)
    # dp[i][w] = i번째 아이템까지 고려, 용량 w일 때 최대 가치
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for w in range(capacity + 1):
            # i번째 아이템을 넣지 않는 경우
            dp[i][w] = dp[i-1][w]

            # i번째 아이템을 넣는 경우
            if weights[i-1] <= w:
                dp[i][w] = max(
                    dp[i][w],
                    dp[i-1][w - weights[i-1]] + values[i-1]
                )

    return dp[n][capacity]

# 공간 최적화: O(n*W) -> O(W)
def knapsack_optimized(weights, values, capacity):
    dp = [0] * (capacity + 1)

    for i in range(len(weights)):
        # 역순으로 순회 (이전 상태 보존)
        for w in range(capacity, weights[i] - 1, -1):
            dp[w] = max(dp[w], dp[w - weights[i]] + values[i])

    return dp[capacity]
```

최장 증가 부분 수열(LIS)은 각 원소에서 끝나는 수열의 길이를 저장하는 O(n²) 풀이와, 길이별 마지막 원소의 최솟값을 관리하는 O(n log n) 풀이를 비교한다. 두 번째 구현은 이진 탐색으로 현재 원소가 들어갈 위치를 찾는다.

```python
# 4. 최장 증가 부분 수열 (LIS)
# O(n²) 풀이
def lis_n2(arr):
    n = len(arr)
    dp = [1] * n  # dp[i] = arr[i]로 끝나는 LIS 길이

    for i in range(1, n):
        for j in range(i):
            if arr[j] < arr[i]:
                dp[i] = max(dp[i], dp[j] + 1)

    return max(dp)

# O(n log n) 풀이 - 이진 탐색 활용
import bisect

def lis_nlogn(arr):
    tails = []  # tails[i] = 길이 i+1인 증가 수열의 마지막 원소 최솟값

    for num in arr:
        idx = bisect.bisect_left(tails, num)
        if idx == len(tails):
            tails.append(num)
        else:
            tails[idx] = num

    return len(tails)
```
