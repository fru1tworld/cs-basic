# 마스터 정리

마스터 정리(Master Theorem)는 분할 정복 점화식 `T(n) = aT(n/b) + f(n)`의 증가율을 세 가지 경우로 나누어 구하는 정리다. 1980년 Bentley, Haken, Saxe가 제시했으며, 재귀 호출의 비용과 분할·병합 비용 중 어느 쪽이 지배적인지 비교한다.

## 마스터 정리의 형태

- 분할 정복 점화식:
- T(n) = aT(n/b) + f(n)
- where:
- a ≥ 1: 부분 문제의 개수
- b > 1: 문제 크기 축소 비율
- f(n): 분할과 병합 비용 (점근적으로 양수)

재귀 트리의 리프 수는 `n^(log_b a)`다. 이 값과 f(n)의 성장률을 비교하면 비용이 리프 쪽에 집중되는지, 모든 레벨에 비슷하게 분포하는지, 루트 쪽에 집중되는지 나눌 수 있다.

## 세 가지 케이스

| 경우 | 조건 | 해 |
| --- | --- | --- |
| Case 1: 리프 비용이 지배 | 어떤 ε > 0에 대해 f(n) = O(n^(log_b a - ε)) | T(n) = Θ(n^(log_b a)) |
| Case 2: 레벨별 비용이 균형 | f(n) = Θ(n^(log_b a)) | T(n) = Θ(n^(log_b a) log n) |
| Case 3: 루트 비용이 지배 | 어떤 ε > 0에 대해 f(n) = Ω(n^(log_b a + ε)), 정규 조건 만족 | T(n) = Θ(f(n)) |

- 정규 조건 (Regularity Condition):
- Case 3에서 추가로 필요:
- af(n/b) ≤ cf(n) for some c < 1 and all sufficiently large n
- 이는 f(n)이 "규칙적으로 증가"함을 보장
- 대부분의 다항식 f(n)은 이 조건을 만족

## 직관적 이해

재귀 트리의 루트 비용은 f(n), 다음 레벨의 비용은 a×f(n/b), 그다음은 a²×f(n/b²)다. 이를 깊이 log_b n까지 합산한다.

Case 1은 아래로 내려갈수록 비용이 커져 리프 비용이 지배한다. Case 2는 각 레벨의 비용이 같은 차수이므로 레벨 수만큼 곱해 log n이 추가된다. Case 3은 반대로 위쪽 비용이 지배하므로, 정규 조건 아래에서 전체 비용이 f(n)과 같은 차수가 된다.

## 예제별 적용

- Case 1 예제: T(n) = 9T(n/3) + n
- a = 9, b = 3, f(n) = n
- n^(log_b a) = n^(log_3 9) = n^2
- f(n) = n vs n^2
- n = O(n^(2-ε)) for ε = 1
- → Case 1 적용
- → T(n) = Θ(n²)

- Case 2 예제: T(n) = 2T(n/2) + n (Merge Sort)
- a = 2, b = 2, f(n) = n
- n^(log_b a) = n^(log_2 2) = n^1 = n
- f(n) = n = Θ(n^1) = Θ(n^(log_b a))
- → Case 2 적용
- → T(n) = Θ(n log n)

- Case 2 예제: T(n) = T(n/2) + 1 (Binary Search)
- a = 1, b = 2, f(n) = 1
- n^(log_b a) = n^(log_2 1) = n^0 = 1
- f(n) = 1 = Θ(1) = Θ(n^(log_b a))
- → Case 2 적용
- → T(n) = Θ(log n)

- Case 3 예제: T(n) = 3T(n/4) + n log n
- a = 3, b = 4, f(n) = n log n
- n^(log_b a) = n^(log_4 3) ≈ n^0.79
- f(n) = n log n vs n^0.79
- n log n = Ω(n^(0.79+ε)) for ε = 0.2 (예: n^0.99도 가능)
- 정규 조건 확인:
- af(n/b) = 3 × (n/4) log(n/4)
- = (3n/4)(log n - log 4)
- ≤ (3/4) n log n
- = cf(n) where c = 3/4 < 1 가능
- → Case 3 적용
- → T(n) = Θ(n log n)

## 적용 불가 사례

f(n)이 비교 기준보다 작거나 크다는 사실만으로 Case 1이나 Case 3을 적용할 수는 없다. 두 경우에는 양의 ε에 해당하는 다항식 차이가 필요하다. 다음 점화식은 그 사이에 놓이는 예다.
- T(n) = 2T(n/2) + n/log n
- a = 2, b = 2
- n^(log_b a) = n
- f(n) = n/log n
- Case 1 확인: f(n) = O(n^(1-ε))?
- n/log n = O(n^0.99)? → lim(n/log n)/(n^0.99) = lim n^0.01/log n → ∞
- → Case 1 아님
- Case 2 확인: f(n) = Θ(n)?
- n/log n = Θ(n)? → No, n/log n = o(n)
- → Case 2 아님
- Case 3: f(n) = Ω(n^(1+ε))?
- n/log n = Ω(n^1.01)? → No
- → Case 3 아님
- → 마스터 정리 적용 불가!
- → 다른 방법 필요 (재귀 트리, 대입법 등)

로그 인자가 붙은 일부 형태는 확장 마스터 정리(Extended Master Theorem)로 다룰 수 있다. 아래는 k ≥ 0인 경우의 Case 2 확장이다.
- f(n) = Θ(n^(log_b a) × (log n)^k) for k ≥ 0
- → T(n) = Θ(n^(log_b a) × (log n)^(k+1))
- 예: T(n) = 2T(n/2) + n log n
- a = 2, b = 2, f(n) = n log n = n × (log n)^1
- k = 1
- → T(n) = Θ(n × (log n)^2)

## 증명 스케치

- 재귀 트리를 이용한 증명:
- 총 비용 = (비분할 비용의 합) + (리프 비용)
- = Σ(j=0 to log_b n - 1) a^j × f(n/b^j) + Θ(n^(log_b a))
- g(n) = Σ(j=0 to log_b n - 1) a^j × f(n/b^j)
- Case 1: g(n) = O(n^(log_b a))
- → 리프가 지배 → T(n) = Θ(n^(log_b a))
- Case 2: g(n) = Θ(n^(log_b a) × log n)
- → 각 레벨 동일 → T(n) = Θ(n^(log_b a) log n)
- Case 3: g(n) = Θ(f(n))
- → 루트가 지배 → T(n) = Θ(f(n))

## 핵심 정리

### 외워야 할 공식

- T(n) = aT(n/b) + f(n), c_crit = log_b(a)
- f(n) = O(n^(c_crit - ε)), →, T(n) = Θ(n^c_crit)
- f(n) = Θ(n^c_crit), →, T(n) = Θ(n^c_crit log n)
- f(n) = Ω(n^(c_crit + ε)), →, T(n) = Θ(f(n)), [+ regularity]

### 자주 나오는 패턴

- T(n) = T(n/2) + O(1), → Θ(log n), [Binary Search]
- T(n) = T(n/2) + O(n), → Θ(n), [Case 3]
- T(n) = 2T(n/2) + O(1), → Θ(n), [Case 1]
- T(n) = 2T(n/2) + O(n), → Θ(n log n), [Merge Sort]
- T(n) = 2T(n/2) + O(n²), → Θ(n²), [Case 3]
- T(n) = 3T(n/2) + O(n), → Θ(n^1.58...), [Case 1, Karatsuba]
- T(n) = 4T(n/2) + O(n), → Θ(n²), [Case 1]
- T(n) = 4T(n/2) + O(n²), → Θ(n² log n), [Case 2]
- T(n) = 7T(n/2) + O(n²), → Θ(n^2.81...), [Strassen]
- T(n) = 8T(n/2) + O(n²), → Θ(n³), [Naive Matrix]
