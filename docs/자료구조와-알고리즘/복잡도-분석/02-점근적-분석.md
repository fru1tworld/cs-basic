# 점근적 분석

점근적 분석은 입력 크기가 커질 때 알고리즘의 자원 사용량이 얼마나 빠르게 증가하는지 살펴보는 방법이다. 상수 계수와 낮은 차수의 항보다 성장률에 집중하므로, 큰 입력에서 서로 다른 알고리즘을 비교하는 데 사용한다.

## 시간/공간 복잡도 분석

### Big-O 표기법

입력 크기 n에 대한 비용 함수의 상한을 표현할 때 Big-O를 사용한다. 대표적인 증가율은 충분히 큰 입력에서 상수, 로그, 선형, 선형 로그, 제곱, 지수, 팩토리얼 순으로 커지며, 각각 `O(1)`, `O(log n)`, `O(n)`, `O(n log n)`, `O(n²)`, `O(2^n)`, `O(n!)`로 표현한다. 실제 실행 시간에는 생략한 상수 계수와 입력 크기도 영향을 준다.

## 점근적 표기법 (Asymptotic Notation)

Big-O와 Big-Ω는 각각 함수의 상한과 하한이다. 최악·평균·최선 실행 시간 중 무엇을 분석하는지 먼저 정한 뒤, 그 함수에 대한 상한이나 하한을 표현한다. 아래 정의에서는 충분히 큰 입력에서 비용 함수가 음수가 아니고 비교 함수는 양수라고 가정한다.

- Big-O (상한):
- f(n) = O(g(n)) ⟺ ∃c > 0, n₀ > 0 : ∀n ≥ n₀, f(n) ≤ c × g(n)
- Big-Ω (하한):
- f(n) = Ω(g(n)) ⟺ ∃c > 0, n₀ > 0 : ∀n ≥ n₀, f(n) ≥ c × g(n)
- Big-Θ (타이트 바운드):
- f(n) = Θ(g(n)) ⟺ f(n) = O(g(n)) ∧ f(n) = Ω(g(n))
- ⟺ ∃c₁, c₂ > 0, n₀ > 0 : ∀n ≥ n₀, c₁ × g(n) ≤ f(n) ≤ c₂ × g(n)

- Little-o, Little-ω (엄격한 바운드):
- f(n) = o(g(n)) ⟺ lim(n→∞) f(n)/g(n) = 0
- f(n) = ω(g(n)) ⟺ lim(n→∞) f(n)/g(n) = ∞

다음 예제는 양의 상수와 시작점 n₀를 직접 골라 다항식의 상한과 하한을 보인다.

```python
def prove_big_o():
    """
    증명: 3n² + 2n + 1 = O(n²)

    c = 6, n₀ = 1로 설정

    n ≥ 1일 때:
    3n² + 2n + 1 ≤ 3n² + 2n² + n²  (∵ n ≥ 1이면 1 ≤ n²)
                = 6n²

    따라서 3n² + 2n + 1 ≤ 6 × n² for all n ≥ 1 성립
    """
    pass

def prove_big_theta():
    """
    증명: 3n² + 2n + 1 = Θ(n²)

    상한 (O): 위에서 증명

    하한 (Ω): c = 3, n₀ = 1
    3n² + 2n + 1 ≥ 3n² for all n ≥ 1 성립

    따라서 3 × n² ≤ 3n² + 2n + 1 ≤ 6 × n² for all n ≥ 1
    → Θ(n²)
    """
    pass
```

- 점근적 표기법의 성질:
- 전이성 (Transitivity):
- f(n) = O(g(n)) ∧ g(n) = O(h(n)) → f(n) = O(h(n))
- 반사성 (Reflexivity):
- f(n) = O(f(n)), f(n) = Θ(f(n)), f(n) = Ω(f(n))
- 대칭성 (Symmetry):
- f(n) = Θ(g(n)) ⟺ g(n) = Θ(f(n))
- 전치 대칭성 (Transpose Symmetry):
- f(n) = O(g(n)) ⟺ g(n) = Ω(f(n))
- 덧셈:
- O(f(n)) + O(g(n)) = O(max(f(n), g(n)))
- 곱셈:
- O(f(n)) × O(g(n)) = O(f(n) × g(n))

## 왜 점근적 분석을 사용하는가?

실행 시간 대신 연산 횟수를 분석하면 특정 하드웨어의 속도와 분리해서 알고리즘을 비교할 수 있다. 상수와 낮은 차수의 항을 생략하는 것도 입력이 커질 때 지배적인 비용을 찾기 위해서다. 이 비교를 바탕으로 입력 규모가 늘어날 때의 동작을 예측한다.

## Big-O 표기법 (상한)

- 정의: f(n) = O(g(n))이면, 양의 상수 c와 n₀가 존재하여 모든 n ≥ n₀에 대해 0 ≤ f(n) ≤ c × g(n)

- 수학적 정의:
- f(n) = O(g(n)) ⟺ ∃c > 0, ∃n₀ > 0 : ∀n ≥ n₀, 0 ≤ f(n) ≤ c × g(n)

- 직관적 의미: f(n)은 g(n)보다 "빠르게 증가하지 않음" (상한)

- 예시 증명: 2n² + 3n + 1 = O(n²)

- 증명:
- 2n² + 3n + 1 ≤ 2n² + 3n² + n² = 6n² (n ≥ 1일 때)
- 따라서 c = 6, n₀ = 1로 설정하면 조건 만족
- ∴ 2n² + 3n + 1 = O(n²)

## Big-Ω 표기법 (하한)

- 정의: f(n) = Ω(g(n))이면, 양의 상수 c와 n₀가 존재하여 모든 n ≥ n₀에 대해 0 ≤ c × g(n) ≤ f(n)

- 수학적 정의:
- f(n) = Ω(g(n)) ⟺ ∃c > 0, ∃n₀ > 0 : ∀n ≥ n₀, 0 ≤ c × g(n) ≤ f(n)

- 직관적 의미: f(n)은 g(n)보다 "느리게 증가하지 않음" (하한)

- 예시 증명: 2n² + 3n + 1 = Ω(n²)

- 증명:
- 2n² + 3n + 1 ≥ 2n² (n ≥ 1일 때)
- 따라서 c = 2, n₀ = 1로 설정하면 조건 만족
- ∴ 2n² + 3n + 1 = Ω(n²)

## Big-Θ 표기법 (타이트 바운드)

- 정의: f(n) = Θ(g(n))이면, f(n) = O(g(n))이고 f(n) = Ω(g(n))

- 수학적 정의:
- f(n) = Θ(g(n)) ⟺ ∃c₁ > 0, ∃c₂ > 0, ∃n₀ > 0 : ∀n ≥ n₀, c₁ × g(n) ≤ f(n) ≤ c₂ × g(n)

- 직관적 의미: f(n)과 g(n)은 "같은 속도로 증가함" (정확한 증가율)

- 예시 증명: 2n² + 3n + 1 = Θ(n²)

- 증명:
- 상한: 2n² + 3n + 1 ≤ 6n² (위에서 증명)
- 하한: 2n² + 3n + 1 ≥ 2n² (위에서 증명)
- 따라서 c₁ = 2, c₂ = 6, n₀ = 1로 설정하면 조건 만족
- ∴ 2n² + 3n + 1 = Θ(n²)

## Little-o 표기법 (엄격한 상한)

- 정의: f(n) = o(g(n))이면, 모든 양의 상수 c에 대해 n₀가 존재하여 모든 n ≥ n₀에 대해 0 ≤ f(n) < c × g(n)

- 수학적 정의:
- f(n) = o(g(n)) ⟺ lim(n→∞) f(n)/g(n) = 0

- 직관적 의미: f(n)은 g(n)보다 "엄격하게 느리게 증가함"

- 예시: n = o(n²), n log n = o(n²), n² = o(n³)

## Little-ω 표기법 (엄격한 하한)

- 정의: f(n) = ω(g(n))이면, 모든 양의 상수 c에 대해 n₀가 존재하여 모든 n ≥ n₀에 대해 0 ≤ c × g(n) < f(n)

- 수학적 정의:
- f(n) = ω(g(n)) ⟺ lim(n→∞) f(n)/g(n) = ∞

- 직관적 의미: f(n)은 g(n)보다 "엄격하게 빠르게 증가함"

- 예시: n² = ω(n), n³ = ω(n²)

## 점근적 표기법의 성질

### Transitivity (이행성)

- f(n) = O(g(n)) ∧ g(n) = O(h(n)) ⟹ f(n) = O(h(n))
- f(n) = Ω(g(n)) ∧ g(n) = Ω(h(n)) ⟹ f(n) = Ω(h(n))
- f(n) = Θ(g(n)) ∧ g(n) = Θ(h(n)) ⟹ f(n) = Θ(h(n))
- f(n) = o(g(n)) ∧ g(n) = o(h(n)) ⟹ f(n) = o(h(n))
- f(n) = ω(g(n)) ∧ g(n) = ω(h(n)) ⟹ f(n) = ω(h(n))

### Reflexivity (반사성)

- f(n) = O(f(n))
- f(n) = Ω(f(n))
- f(n) = Θ(f(n))

### Symmetry (대칭성)

- f(n) = Θ(g(n)) ⟺ g(n) = Θ(f(n))

### Transpose Symmetry (전치 대칭성)

- f(n) = O(g(n)) ⟺ g(n) = Ω(f(n))
- f(n) = o(g(n)) ⟺ g(n) = ω(f(n))

## 표기법 간 관계

각 표기법의 관계는 부등호에 비유해 기억할 수 있다. 함수값 자체의 대소 비교가 아니라, 충분히 큰 입력에서의 성장 관계를 나타내는 비유다.

| 표기 | 비유 | 관계 |
| --- | --- | --- |
| O | ≤ | 상한 |
| Ω | ≥ | 하한 |
| Θ | = | 같은 차수 |
| o | < | 엄격한 상한 |
| ω | > | 엄격한 하한 |

## 자주 사용되는 점근적 분석 기법

### 다항식 판정

- p(n) = aₖnᵏ + aₖ₋₁nᵏ⁻¹ + ... + a₁n + a₀ (aₖ > 0)
- 이면 p(n) = Θ(nᵏ)

### 로그 법칙

- log_a(n) = Θ(log_b(n)), (모든 양의 상수 a, b > 1에 대해)
- → 밑이 무엇이든 로그의 점근적 복잡도는 동일

### 지수 vs 다항식

- nᵏ = o(aⁿ) (a > 1, k ≥ 0)
- → 어떤 다항식도 지수 함수보다 느리게 증가

### 로그 vs 다항식

- logᵏ(n) = o(nᵉ) (k, ε > 0)
- → 어떤 로그 거듭제곱도 다항식보다 느리게 증가
