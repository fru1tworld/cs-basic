# 점화식

재귀 알고리즘은 현재 문제를 처리하면서 더 작은 문제를 다시 호출한다. 점화식(Recurrence Relation)은 현재 입력의 비용을 이 부분 문제들의 비용과 연결해 표현한다. 식을 풀면 재귀 호출을 남기지 않는 닫힌 형태(closed form)나 점근적 증가율을 구할 수 있다.

## 점화식의 형태

같은 크기의 부분 문제 a개로 나누는 분할 정복은 `T(n) = aT(n/b) + f(n)`으로 표현할 수 있다. n/b는 부분 문제의 크기이고, f(n)은 문제를 나누고 결과를 합치는 비용이다.

크기를 일정한 비율로 줄이지 않고 앞선 항들을 사용하는 선형 점화식은 `T(n) = c₁T(n-1) + c₂T(n-2) + ... + cₖT(n-k) + f(n)`의 형태를 갖는다. 다음 코드에서 병합 정렬·이진 탐색과 피보나치 재귀가 어떤 차이를 보이는지 확인할 수 있다.

```python
# Merge Sort: T(n) = 2T(n/2) + O(n)
def merge_sort(arr):
    if len(arr) <= 1:
        return arr
    mid = len(arr) // 2
    left = merge_sort(arr[:mid])    # T(n/2)
    right = merge_sort(arr[mid:])   # T(n/2)
    return merge(left, right)        # O(n)

# Binary Search: T(n) = T(n/2) + O(1)
def binary_search(arr, target, lo, hi):
    if lo > hi:
        return -1
    mid = (lo + hi) // 2
    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        return binary_search(arr, target, mid + 1, hi)  # T(n/2)
    else:
        return binary_search(arr, target, lo, mid - 1)  # T(n/2)
    # 비교 비용: O(1)

# Fibonacci (naive): T(n) = T(n-1) + T(n-2) + O(1)
def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)  # T(n-1) + T(n-2)
```

## Substitution Method (대입법)

대입법은 먼저 해의 형태를 추측한 뒤, 그 형태를 점화식에 대입해 귀납적으로 증명한다. 증가율이 맞더라도 기저 조건을 만족하지 못할 수 있으므로, 상수와 작은 입력의 조건까지 함께 확인해야 한다.

- 예제 1: Merge Sort
- 점화식: T(n) = 2T(n/2) + n, T(1) = 1
- 추측: T(n) = O(n log n), 즉 T(n) ≤ cn log n for some c > 0
- 귀납적 증명:
- 기저: T(1) = 1 ≤ c × 1 × log(1) = 0 (실패)
- → 기저 조건 수정 필요
- 기저 수정: T(n) ≤ cn log n + n for n ≥ 1
- 귀납 단계: n/2에서 성립한다고 가정
- T(n) = 2T(n/2) + n
- ≤ 2(c(n/2)log(n/2) + n/2) + n
- = cn log(n/2) + n + n
- = cn log n - cn log 2 + 2n
- = cn log n - cn + 2n
- ≤ cn log n (if c ≥ 2)
- 따라서 T(n) = O(n log n) 가능

- 예제 2: T(n) = T(n/3) + T(2n/3) + n
- 추측: T(n) = O(n log n)
- 증명:
- T(n) ≤ c(n/3)log(n/3) + c(2n/3)log(2n/3) + n
- = cn/3 × (log n - log 3) + 2cn/3 × (log n - log(3/2)) + n
- = cn log n - cn/3 × log 3 - 2cn/3 × log(3/2) + n
- = cn log n - cn(log 3/3 + 2log(3/2)/3) + n
- ≤ cn log n (if c is large enough)
- ∵ log 3/3 + 2log(3/2)/3 ≈ 0.53 + 0.39 = 0.92 > 0

- 흔한 실수와 해결:
- 잘못된 추측: T(n) = 2T(n/2) + n, 추측 T(n) ≤ cn
- T(n) = 2T(n/2) + n
- ≤ 2 × c(n/2) + n
- = cn + n
- = (c+1)n, (cn보다 큼!)
- 문제: 상수가 n에 추가됨
- 해결: 더 정밀한 추측 (예: cn log n) 또는 하한 빼기
- 개선된 추측: T(n) ≤ cn log n - bn
- T(n) = 2T(n/2) + n
- ≤ 2(c(n/2)log(n/2) - b(n/2)) + n
- = cn log(n/2) - bn + n
- = cn log n - cn - bn + n
- = cn log n - bn - (c-1)n
- ≤ cn log n - bn (if c ≥ 1) 가능

## Recursion Tree Method (재귀 트리)

재귀 트리는 호출마다 드는 비용을 트리의 노드에 놓고, 같은 깊이의 비용을 합산한다. `T(n) = 3T(n/4) + cn²`에서는 부분 문제가 세 개로 늘어나는 동안 각 문제의 크기는 1/4로 줄어든다.

```text
Level 0:           cn²                        비용: cn²
                 /  |  \
Level 1:     c(n/4)² × 3                      비용: 3c(n/4)² = (3/16)cn²
             /|\   /|\   /|\
Level 2:  c(n/16)² × 9                        비용: 9c(n/16)² = (3/16)²cn²
           ...

레벨 i의 비용: (3/16)ⁱ × cn²
총 레벨 수: log₄n (n/4^i = 1일 때 i = log₄n)
리프 개수: 3^(log₄n) = n^(log₄3)

총 비용:
T(n) = Σ(i=0 to log₄n) (3/16)ⁱ × cn² + Θ(n^(log₄3))
     = cn² × Σ(i=0 to ∞) (3/16)ⁱ + Θ(n^0.79...)
     = cn² × 1/(1 - 3/16) + Θ(n^0.79...)
     = cn² × 16/13 + Θ(n^0.79...)
     = Θ(n²)  (∵ n² >> n^0.79)
```

같은 트리를 호출 관계 중심으로 그리면 다음과 같다.

```text
cn²                    ← Level 0: cn²
                  / | \
         c(n/4)²  ...  c(n/4)²             ← Level 1: 3×c(n/4)² = 3cn²/16
           /|\         /|\
          ...         ...                   ← Level 2: 9×c(n/16)² = 9cn²/256
          ...         ...
         T(1) ... T(1) ... T(1)            ← Level log₄n: n^(log₄3) leaves
```

부분 문제의 크기가 다르면 경로별 깊이도 달라진다. `T(n) = T(n/3) + T(2n/3) + n`에서는 짧은 경로와 긴 경로를 비교해 비용의 범위를 구한다.

```text
Level 0:              n                     비용: n
                    /   \
Level 1:         n/3   2n/3                 비용: n/3 + 2n/3 = n
                / \    / \
Level 2:     n/9 2n/9 2n/9 4n/9            비용: n

모든 레벨의 비용이 n

최소 깊이: log₃n (n/3만 따라가는 경로)
최대 깊이: log(3/2)n (2n/3만 따라가는 경로)

총 비용:
Ω(n × log₃n) ≤ T(n) ≤ O(n × log(3/2)n)
→ T(n) = Θ(n log n)
```

## 선형 점화식 풀이

`T(n) = c₁T(n-1) + c₂T(n-2) + ... + cₖT(n-k)` 형태의 선형 점화식은 특성 방정식 `x^k = c₁x^(k-1) + c₂x^(k-2) + ... + cₖ`을 이용한다. 방정식의 근으로 일반해를 구성하고 초기 조건으로 계수를 정한다.

- 예제: 피보나치 수열
- 점화식: F(n) = F(n-1) + F(n-2), F(0) = 0, F(1) = 1
- 특성 방정식: x² = x + 1
- x² - x - 1 = 0
- 근: x = (1 ± √5) / 2
- φ = (1 + √5) / 2 ≈ 1.618 (황금비)
- ψ = (1 - √5) / 2 ≈ -0.618
- 일반해: F(n) = Aφⁿ + Bψⁿ
- 초기 조건으로 A, B 결정:
- F(0) = A + B = 0
- F(1) = Aφ + Bψ = 1
- 풀면: A = 1/√5, B = -1/√5
- 닫힌 형태:
- F(n) = (φⁿ - ψⁿ) / √5
- = (φⁿ - ψⁿ) / √5
- `≈ φⁿ / √5 (∵ |ψ| < 1)`
- = Θ(1.618ⁿ)

- 중복근이 있는 경우:
- 점화식: T(n) = 4T(n-1) - 4T(n-2)
- 특성 방정식: x² - 4x + 4 = 0
- (x - 2)² = 0
- x = 2 (중복근)
- 일반해: T(n) = (A + Bn) × 2ⁿ
- 초기 조건으로 A, B 결정

## 비동차 점화식

비동차 점화식에는 이전 항들의 결합 외에 f(n) 같은 항이 추가된다. `T(n) = aT(n-1) + f(n)`에서는 동차해와 f(n)에 대응하는 특수해를 더해 일반해를 구한다.

- 예제: T(n) = 2T(n-1) + n, T(0) = 0
- 특수해 찾기: f(n) = n
- 추측: T_p(n) = An + B
- T_p(n) = 2T_p(n-1) + n
- An + B = 2(A(n-1) + B) + n
- An + B = 2An - 2A + 2B + n
- An + B = (2A + 1)n + (2B - 2A)
- 계수 비교:
- A = 2A + 1 → A = -1
- B = 2B - 2A → B = 2A = -2
- 특수해: T_p(n) = -n - 2
- 동차해: T_h(n) = c × 2ⁿ
- 일반해: T(n) = c × 2ⁿ - n - 2
- 초기 조건: T(0) = c - 0 - 2 = 0 → c = 2
- 최종: T(n) = 2^(n+1) - n - 2 = Θ(2ⁿ)

## 연습 문제

### 문제 1: 다음 점화식을 풀어라

- a) T(n) = 2T(n/2) + n²
- b) T(n) = T(n-1) + n
- c) T(n) = 2T(n-1) + 1, T(1) = 1
- d) T(n) = T(n/2) + T(n/4) + n

### 문제 2: 다음 알고리즘의 점화식을 세우고 풀어라

```python
def mystery(n):
    if n <= 1:
        return 1
    count = 0
    for i in range(n):
        count += 1
    return mystery(n // 2) + mystery(n // 2) + count
```

### 풀이

- 문제 1:
- a) T(n) = 2T(n/2) + n²
- 재귀 트리: 레벨 i에서 비용 = 2ⁱ × (n/2ⁱ)² = n²/2ⁱ
- 총합: n² × Σ(1/2)ⁱ = n² × 2 = Θ(n²)
- b) T(n) = T(n-1) + n
- T(n) = n + (n-1) + ... + 1 = n(n+1)/2 = Θ(n²)
- c) T(n) = 2T(n-1) + 1
- 특성방정식: x = 2 → T_h = c × 2ⁿ
- 특수해: T_p = -1
- 일반해: T(n) = c × 2ⁿ - 1
- T(1) = 2c - 1 = 1 → c = 1
- T(n) = 2ⁿ - 1 = Θ(2ⁿ)
- d) T(n) = T(n/2) + T(n/4) + n
- 추측: T(n) = O(n)
- T(n) ≤ cn/2 + cn/4 + n = 3cn/4 + n
- ≤ cn (if c ≥ 4)
- → T(n) = Θ(n)
- 문제 2:
- 점화식: T(n) = 2T(n/2) + n
- → Master Theorem Case 2: T(n) = Θ(n log n)
