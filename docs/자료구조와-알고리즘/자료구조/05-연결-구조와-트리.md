# 연결 구조와 트리

## 핵심 자료구조

### LinkedList (연결 리스트)

연결 리스트는 각 노드에 데이터와 다음 노드의 참조를 저장한다. A, B, C, D를 순서대로 연결했다면 Head에서 A를 시작으로 `next`를 따라가며 마지막 D의 `next`는 null이다. 이중 연결 리스트는 여기에 이전 노드를 가리키는 `prev`도 두어 양방향으로 이동한다.

- 연산: 맨 앞 삽입/삭제:
  - 시간 복잡도: O(1)
- 연산: 맨 뒤 삽입/삭제 (tail 유지 시):
  - 시간 복잡도: O(1)
- 연산: 중간 삽입/삭제 (위치 알 때):
  - 시간 복잡도: O(1)
- 연산: 인덱스 접근:
  - 시간 복잡도: O(n)
- 연산: 탐색:
  - 시간 복잡도: O(n)

```python
# Python - LinkedList 구현
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

class LinkedList:
    def __init__(self):
        self.head = None
        self.size = 0

    def add_first(self, data):  # O(1)
        new_node = Node(data)
        new_node.next = self.head
        self.head = new_node
        self.size += 1

    def add_last(self, data):  # O(n) - tail 없는 경우
        new_node = Node(data)
        if not self.head:
            self.head = new_node
            return
        current = self.head
        while current.next:
            current = current.next
        current.next = new_node
        self.size += 1

    def remove(self, data):  # O(n)
        if not self.head:
            return False
        if self.head.data == data:
            self.head = self.head.next
            self.size -= 1
            return True
        current = self.head
        while current.next:
            if current.next.data == data:
                current.next = current.next.next
                self.size -= 1
                return True
            current = current.next
        return False
```

### Stack (스택)

스택은 마지막에 넣은 원소를 먼저 꺼내는 LIFO(Last In First Out) 구조다. A, B, C, D 순서로 넣으면 맨 위인 Top은 D이고, 꺼낼 때도 D부터 나온다. 아래 괄호 검사 예제는 가장 최근의 여는 괄호부터 닫는 괄호와 짝을 맞춘다.

```java
// Java - Stack 구현 및 활용
public class StackExample {
    public static void main(String[] args) {
        // java.util.Stack 사용 (Vector 기반, 권장하지 않음)
        Stack<Integer> stack = new Stack<>();

        // Deque 사용 권장
        Deque<Integer> betterStack = new ArrayDeque<>();
        betterStack.push(1);  // O(1)
        betterStack.push(2);
        int top = betterStack.pop();  // O(1), 2 반환
        int peek = betterStack.peek();  // O(1), 1 반환 (제거 안함)
    }

    // 활용 예: 괄호 유효성 검사
    public static boolean isValidParentheses(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        Map<Character, Character> pairs = Map.of(
            ')', '(',
            '}', '{',
            ']', '['
        );

        for (char c : s.toCharArray()) {
            if (c == '(' || c == '{' || c == '[') {
                stack.push(c);
            } else if (pairs.containsKey(c)) {
                if (stack.isEmpty() || stack.pop() != pairs.get(c)) {
                    return false;
                }
            }
        }
        return stack.isEmpty();
    }
}
```

### Queue (큐)

큐는 먼저 넣은 원소를 먼저 꺼내는 FIFO(First In First Out) 구조다. Rear에 새 원소를 넣고 Front에서 꺼내므로 A부터 H까지 넣었다면 A부터 나온다. 뒤의 우선순위 큐 예제는 이 삽입 순서 대신 우선순위로 꺼낼 항목을 결정한다.

```python
from collections import deque
import queue

# deque 사용 (일반적인 경우)
q = deque()
q.append(1)     # enqueue - O(1)
q.append(2)
front = q.popleft()  # dequeue - O(1)

# Priority Queue (우선순위 큐)
import heapq

pq = []
heapq.heappush(pq, (3, "low"))      # O(log n)
heapq.heappush(pq, (1, "high"))
heapq.heappush(pq, (2, "medium"))

# 우선순위가 높은(숫자가 낮은) 순서로 pop
while pq:
    priority, task = heapq.heappop(pq)  # O(log n)
    print(f"{task}: {priority}")
# 출력: high: 1, medium: 2, low: 3
```

### Tree (트리)

이진 탐색 트리(BST)는 각 노드를 기준으로 왼쪽 서브트리에 작은 값, 오른쪽 서브트리에 큰 값을 둔다. 예를 들어 루트가 8이고 나머지 값이 3, 10, 1, 6, 14, 13, 4, 7이라면 이 규칙에 따라 가지를 나눈다. 아래 구현은 값을 비교해 삽입 위치를 찾고, 방문 순서에 따라 중위·전위·후위 순회를 수행한다.

```java
// Java - BST 구현
public class BinarySearchTree {
    private Node root;

    private static class Node {
        int value;
        Node left, right;

        Node(int value) {
            this.value = value;
        }
    }

    // O(log n) 평균, O(n) 최악 (편향 트리)
    public void insert(int value) {
        root = insertRecursive(root, value);
    }

    private Node insertRecursive(Node node, int value) {
        if (node == null) return new Node(value);

        if (value < node.value) {
            node.left = insertRecursive(node.left, value);
        } else if (value > node.value) {
            node.right = insertRecursive(node.right, value);
        }
        return node;
    }

    // 중위 순회 (In-order): 정렬된 순서 출력
    public void inOrder(Node node) {
        if (node == null) return;
        inOrder(node.left);     // 왼쪽
        System.out.print(node.value + " ");  // 현재
        inOrder(node.right);    // 오른쪽
    }

    // 전위 순회 (Pre-order): 복사에 유용
    public void preOrder(Node node) {
        if (node == null) return;
        System.out.print(node.value + " ");  // 현재
        preOrder(node.left);    // 왼쪽
        preOrder(node.right);   // 오른쪽
    }

    // 후위 순회 (Post-order): 삭제에 유용
    public void postOrder(Node node) {
        if (node == null) return;
        postOrder(node.left);   // 왼쪽
        postOrder(node.right);  // 오른쪽
        System.out.print(node.value + " ");  // 현재
    }
}
```

#### 균형 이진 트리

- 트리 종류: AVL 트리:
  - 특징: 엄격한 균형 (높이 차 ≤ 1)
  - 삽입/삭제/탐색: O(log n)
- 트리 종류: Red-Black 트리:
  - 특징: 느슨한 균형, Java TreeMap
  - 삽입/삭제/탐색: O(log n)
- 트리 종류: B-트리:
  - 특징: 다진 트리, DB 인덱스
  - 삽입/삭제/탐색: O(log n)
- 트리 종류: B+ 트리:
  - 특징: B-트리 변형, 리프에만 데이터
  - 삽입/삭제/탐색: O(log n)

### Heap (힙)

최대 힙은 부모가 자식보다 크거나 같도록 배치한다. 예를 들어 `[90, 79, 72, 62, 52, 65, 55]`로 저장하면 루트는 90, 그 자식은 79와 72다. 배열 인덱스 i를 기준으로 부모는 `(i-1) / 2`, 왼쪽 자식은 `2*i + 1`, 오른쪽 자식은 `2*i + 2`로 찾는다.

```python
import heapq

# Python heapq는 최소 힙
min_heap = []
heapq.heappush(min_heap, 5)  # O(log n)
heapq.heappush(min_heap, 3)
heapq.heappush(min_heap, 7)
heapq.heappush(min_heap, 1)

print(heapq.heappop(min_heap))  # 1 (최소값)

# 최대 힙 구현 (값에 -1 곱하기)
max_heap = []
for num in [5, 3, 7, 1]:
    heapq.heappush(max_heap, -num)

print(-heapq.heappop(max_heap))  # 7 (최대값)

# 힙 정렬 O(n log n)
def heap_sort(arr):
    heapq.heapify(arr)  # O(n)
    return [heapq.heappop(arr) for _ in range(len(arr))]

# Top K 문제
def find_top_k(arr, k):
    return heapq.nlargest(k, arr)  # O(n log k)
```

### Graph (그래프)

그래프는 정점 사이의 연결을 간선으로 표현한다. 간선에 방향이 없으면 무방향 그래프, A에서 B처럼 방향을 지정하면 방향 그래프다. 비용을 표현해야 한다면 가중치를 붙인다. 아래 가중치 예제는 A-B에 5, A-D에 3, B-C에 2, C-D에 4를 부여한다.

같은 연결 관계도 인접 행렬과 인접 리스트로 표현할 수 있다. 다음 코드에서 두 표현이 저장하는 정보와 공간 비용을 비교한다.

```python
# 그래프 표현 방법

# 1. 인접 행렬 (Adjacency Matrix)
# 공간: O(V²), 간선 확인: O(1)
adj_matrix = [
    [0, 1, 1, 1],  # A -> B, C, D
    [1, 0, 1, 0],  # B -> A, C
    [1, 1, 0, 1],  # C -> A, B, D
    [1, 0, 1, 0],  # D -> A, C
]

# 2. 인접 리스트 (Adjacency List)
# 공간: O(V + E), 간선 확인: O(degree)
adj_list = {
    'A': ['B', 'C', 'D'],
    'B': ['A', 'C'],
    'C': ['A', 'B', 'D'],
    'D': ['A', 'C'],
}

# 가중치 그래프 인접 리스트
weighted_graph = {
    'A': [('B', 5), ('D', 3)],
    'B': [('A', 5), ('C', 2)],
    'C': [('B', 2), ('D', 4)],
    'D': [('A', 3), ('C', 4)],
}
```
