# 프로그래밍 언어 이론 (Programming Language Theory, PLT)

## 구문과 의미론

### PLT-001
구문(Syntax)과 의미론(Semantics)은 각각 무엇을 정의하나요? 문법에 맞는 프로그램이 실행 중 실패하는 예를 들어 설명해 주세요.

### PLT-002
구체 구문과 추상 구문 트리(AST)의 차이는 무엇인가요? 괄호와 연산자 우선순위가 AST에 어떻게 반영되는지 설명해 주세요.

### PLT-003
작은 단계(Small-step)와 큰 단계(Big-step) 연산 의미론의 차이는 무엇인가요? 실행 중간 상태와 종료하지 않는 계산을 다룰 때 어떤 차이가 있나요?

### PLT-004
프로그램의 의미를 정의하는 연산 의미론, 표시 의미론, 공리적 의미론의 차이는 무엇인가요?

## 변수, 바인딩과 함수

### PLT-005
자유 변수와 바인딩된 변수는 어떻게 구분하나요? 렉시컬 스코프와 동적 스코프에서 같은 변수 참조가 다르게 해석되는 예를 들어 주세요.

### PLT-006
클로저는 함수 코드 외에 어떤 환경을 담나요? 변수를 캡처하는 것과 그 변수의 값을 복사하는 것은 어떻게 다른가요?

### PLT-007
람다 계산의 변수, 추상화, 적용은 무엇인가요? 간단한 람다 식으로 함수 적용을 설명해 주세요.

### PLT-008
알파 변환과 베타 축약은 무엇인가요? 치환 과정에서 변수 포획(Variable Capture)을 피해야 하는 이유를 설명해 주세요.

### PLT-009
일급 함수와 고차 함수의 차이는 무엇인가요? 커링과 부분 적용은 어떻게 구분하나요?

## 평가 전략과 상태

### PLT-010
Call by Value, Call by Name, Call by Need는 인자를 언제 평가하나요? 사용하지 않는 인자와 반복 사용되는 인자를 예로 들어 비교해 주세요.

### PLT-011
Call by Value와 Call by Reference는 함수 안에서의 대입에 어떤 차이를 만드나요? 객체 참조를 값으로 전달하는 경우도 함께 설명해 주세요.

### PLT-012
순수 함수와 참조 투명성은 무엇인가요? 부수 효과가 있으면 식을 그 결과값으로 치환하는 변환에 어떤 제약이 생기나요?

### PLT-013
환경(Environment)과 저장소(Store)를 구분하는 이유는 무엇인가요? 별칭(Aliasing)이 있는 가변 상태를 예로 들어 설명해 주세요.

### PLT-014
불변성과 영속 자료구조는 어떻게 다른가요? 구조 공유를 통해 이전 값을 보존하는 방법을 설명해 주세요.

## 타입 시스템

### PLT-015
정적 타입 검사와 동적 타입 검사는 언제 어떤 정보를 확인하나요? 타입 검사를 통과했다는 사실만으로 보장할 수 없는 성질은 무엇인가요?

### PLT-016
타입 판단과 추론 규칙은 무엇인가요? 타입 환경을 사용해 변수 참조와 함수 적용의 타입을 판단하는 과정을 설명해 주세요.

### PLT-017
곱 타입(Product Type), 합 타입(Sum Type), 함수 타입은 어떤 값의 구성을 나타내나요? 각각의 값을 만들고 사용하는 방법을 설명해 주세요.

### PLT-018
Option과 Result 같은 합 타입으로 값의 부재와 실패를 표현하면 호출자는 어떤 경우를 처리해야 하나요?

### PLT-019
타입 추론과 타입 검사는 어떻게 다른가요? 타입 변수를 이용한 제약 생성과 단일화(Unification)를 간단한 예로 설명해 주세요.

### PLT-020
매개변수 다형성(Parametric Polymorphism), 부분형 다형성(Subtype Polymorphism), 임시 다형성(Ad-hoc Polymorphism)의 차이는 무엇인가요?

### PLT-021
구조적 타입 시스템과 명목적 타입 시스템은 타입의 관계를 어떻게 결정하나요? 덕 타이핑과는 어떤 차이가 있나요?

### PLT-022
공변성, 반공변성, 무공변성은 무엇인가요? 함수의 인자와 반환 타입, 읽기와 쓰기가 가능한 컨테이너를 예로 들어 설명해 주세요.

### PLT-023
재귀 타입은 재귀 자료구조를 어떻게 표현하나요? 재귀 타입과 재귀 함수는 어떤 점에서 다른가요?

### PLT-024
패턴 매칭에서 완전성(Exhaustiveness)을 검사하는 이유는 무엇인가요? 타입에 새로운 경우가 추가되면 기존 코드에 어떤 영향을 주나요?

### PLT-025
타입 건전성(Type Soundness)을 진행(Progress)과 보존(Preservation)으로 설명해 주세요. 이 성질이 프로그램의 종료까지 보장하나요?

### PLT-026
의존 타입(Dependent Type)은 일반적인 매개변수화된 타입과 어떻게 다른가요? 벡터의 길이를 타입에 반영하는 예를 들어 주세요.

## 제어 흐름과 효과

### PLT-027
예외와 Result 타입은 실패 시 제어 흐름과 함수의 타입에 어떤 차이를 만드나요? 호출자가 실패 가능성을 확인하는 방법도 비교해 주세요.

### PLT-028
연속(Continuation)은 계산의 어떤 부분을 나타내나요? 연속 전달 방식(CPS)으로 함수 호출 이후의 작업을 표현해 주세요.

### PLT-029
효과 시스템(Effect System)은 반환 타입 외에 어떤 정보를 표현하나요? 상태 변경, 예외, 입출력 중 하나를 예로 들어 주세요.

### PLT-030
선형 타입과 아핀 타입은 값의 사용 횟수에 어떤 제약을 두나요? 자원의 소유권과 해제를 표현할 때 어떻게 활용할 수 있나요?

## 프로그램 동치와 검증

### PLT-031
두 프로그램이 동치인지 판단할 때 관찰하는 대상에 따라 결과가 어떻게 달라지나요? 반환값이 같아도 부수 효과나 종료 여부가 다른 예를 들어 주세요.

### PLT-032
Hoare triple의 사전 조건과 사후 조건은 무엇인가요? 반복문 불변식과 부분 정당성, 전체 정당성을 연결해 설명해 주세요.

## 메타프로그래밍과 언어 구현

### PLT-033
매크로와 함수는 코드를 다루는 단계에 어떤 차이가 있나요? 위생적 매크로(Hygienic Macro)가 변수 포획을 막는 방법을 설명해 주세요.

### PLT-034
컴파일과 해석은 언어 자체의 성질인가요, 구현 방식인가요? 하나의 언어에서 인터프리터, 바이트코드, JIT가 함께 사용될 수 있는지 설명해 주세요.

### PLT-035
컴파일러 최적화가 의미를 보존한다는 것은 무엇인가요? 상수 접기와 평가 순서 변경이 가능한 조건을 예로 들어 주세요.
